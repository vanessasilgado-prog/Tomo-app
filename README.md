# Tomi

App de cocina hecha con React + Vite.

## Desarrollo local
npm install
npm run dev

## Deploy en Vercel
1. Sube esta carpeta a un repositorio en GitHub.
2. Entra a vercel.com -> "Add New Project" -> importa el repositorio.
3. Vercel detecta Vite automáticamente (Build Command: `npm run build`, Output: `dist`). Dale "Deploy".
4. Cuando termine, te da un link (algo como tomi-app.vercel.app) que puedes abrir desde cualquier celular.
